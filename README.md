

vamos a crear un nuevo proyecto que se llama "Salva Quest"
En este proyecto te voy a compartirun texto largo en el que sería ideal tal vez un textfield, en el te voy a ingresar el texto con las misones, abajo, arriba debe estar un botón de confirmación, y a la izquierda un botón para borrar los elementos de este textfield para que esté limpio
te voy a compartir un prompt que uso con la ia para que te ayude a identificar que es lo que quiero

Te voy a pasar una lista de cuentas con sus misiones diarias de Fortnite Salvar el Mundo.


Cada cuenta puede tener entre 1 y 3 misiones (El máximo útil es 3 misiones por cuenta).
Dentro de cada misión, indicar cuántas misiones tiene cada cuenta (ej: "Radmare (2 misiones)").

Necesito que hagas lo siguiente:

1. Agrupes las misiones por nombre.

2. Clasifiques en:

🥇 GRUPALES – PRIORIDAD ALTA 🥇
- Misiones que coincidan entre cuentas
- Ordenar el resultado por prioridad: Primero misiones donde participen cuentas que tengan 3 misiones activas, luego las demás.
- Excluir completamente
- A las cuentas con 3 misiones agregar " (3 misiones) ✅" al lado del nombre
- Ejemplo: Boikson (3 misiones) ✅

🌓 GRUPALES – PRIORIDAD MEDIA 🌓
- Otras misiones que coincidan pero con menor prioridad
- Incluir misiones compartidas por cuentas con 1 o 2 misiones activas

❌ IMPORTANTE:
Excluir completamente de las grupales estas misiones:
- Husk Extermination (todas sus variantes)
- Mission Specialist (todas)
- Party of 25
- Mission Veteran
- All Together Now

3. Luego mostrar:

🔥 INDIVIDUALES – PRIORIDAD ALTA (3 MISIONES) 🔥
- Listar SOLO las cuentas que tengan 3 misiones
- Incluir TODAS sus misiones, incluso las excluidas en grupales (Husk Extermination, etc.)
- Mostrar el nombre de la cuenta
- Debajo, listar sus misiones

🔻 INDIVIDUALES – PRIORIDAD BAJA (2 MISIONES) 🔻

Listar SOLO cuentas que tengan exactamente 2 misiones
SOLO incluir cuentas donde AMBAS misiones sean de tipo "Husk Extermination"
Mostrar el nombre de la cuenta
Debajo, listar sus misiones

Formato obligatorio:

- No agregar explicaciones
- No agregar texto extra
- Solo mostrar las secciones:
  🥇 GRUPALES – PRIORIDAD ALTA
  🌓 GRUPALES – PRIORIDAD MEDIA
  🔥 INDIVIDUALES – PRIORIDAD ALTA
  🔻 INDIVIDUALES – PRIORIDAD BAJA

ADICIONAL PARA LAS SECCIONES GRUPALES:

En todas las misiones mostradas en:
🥇 GRUPALES – PRIORIDAD ALTA 🥇
🌓 GRUPALES – PRIORIDAD MEDIA 🌓

se debe indicar SIEMPRE la cantidad total de misiones activas que tiene cada cuenta, aunque tenga 1, 2 o 3 misiones.

Formato:

Cuenta con 1 misión: NombreCuenta (1 misión)
Cuenta con 2 misiones: NombreCuenta (2 misiones)
Cuenta con 3 misiones: NombreCuenta (3 misiones) ✅

Ejemplos:

SEN Dnk0 (1 misión)
Boikson (2 misiones)
Voemso (3 misiones) ✅

Esta regla aplica a TODAS las cuentas mostradas en las secciones grupales, no solamente a las cuentas con 3 misiones.


- Usar exactamente ese formato visual
